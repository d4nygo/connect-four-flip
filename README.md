# Connect Four Flip

A physical Connect Four board with an Arduino, motors and a ProtoPie phone app. Two players take turns, and the app shows the board live. Build the 4-coin pattern shown on screen and a **Flip** button lights up on the app: press it and the **whole board flips over**, the coins fall the other way, and surprise lines decide the winner.

University project · Hardware and Software Technologies for Design · team of 3.
